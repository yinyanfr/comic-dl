title: CLI 命令
description: 查阅命令、可用选项、标准输出和退出码。
---

运行 `comic-dl --help` 查看命令，或运行 `comic-dl <command> --help` 查看各命令选项。`-h` 等同于 `--help`，`-V` 等同于 `--version`。从仓库运行时，把 `comic-dl` 换成 `node dist/index.js`。

| 命令                      | 用途                                                     |
| ------------------------- | -------------------------------------------------------- |
| `sources`                 | 列出内置和已加载的源 ID；不会创建源会话                  |
| `search [query]`          | 搜索标题；省略关键词可浏览目录，`--page <n>` 从 `1` 开始 |
| `list <series-input>`     | 列出作品章节的稳定 ID 与标题                             |
| `chapter <chapter-input>` | 使用章节直链或源定义的标识下载一章                       |
| `download <series-input>` | 下载整个系列；重复传入 `--chapter <id>` 可选定章节       |

### 选项

| 选项                    | 适用命令                      | 说明                                                                    |
| ----------------------- | ----------------------------- | ----------------------------------------------------------------------- |
| `--config <file>`       | 全部                          | 加载显式 JSON 配置，见[配置参考](../config/)                            |
| `--extension <name>`    | 全部                          | 加载已安装的 npm 包或本地 ESM 文件，可重复                              |
| `--source <id>`         | 除 `sources` 外               | 选择已注册的源；可取自配置                                              |
| `--fixture <directory>` | `list`、`chapter`、`download` | 使用离线测试源；与位置输入或显式 `--source` 互斥                        |
| `--output <directory>`  | `chapter`、`download`         | 必须由命令行或配置提供                                                  |
| `--chapter <id>`        | `download`                    | 采用 `list` 输出的 ID，验证全部 ID 后按阅读顺序处理，重复 ID 只处理一次 |
| `--chapter <id>`        | `chapter --fixture`           | 兼容离线系列样例，只接受一个 ID                                         |
| `--jobs <n>`            | `download`                    | 最大并行章节数，默认 `2`                                                |
| `--retries <n>`         | `chapter`、`download`         | 暂态错误的额外重试次数，默认 `2`，设为 `0` 禁用                         |

### 脚本输出与退出码

`sources` 每行一个源 ID。`list` 输出 `章节 ID<TAB>标题`，`search` 输出 `作品 URL<TAB>标题`；下一页提示和错误写入标准错误。下载进度和汇总供人阅读，不作为机器可读格式。

| 退出码 | 含义                                                                       |
| ------ | -------------------------------------------------------------------------- |
| `0`    | 命令完成；系列中只要有章节成功或已有完整归档，且其余仅受访问限制，仍算成功 |
| `1`    | 运行失败、下载有失败章节，或所选章节全部受限                               |
| `2`    | 命令行用法、配置文件或所选章节 ID 有误                                     |
| `130`  | 用户中断，已完成的归档保留                                                 |
