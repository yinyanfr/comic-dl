## 同时使用多个漫画源

`list`、`chapter` 和 `download` 按以下顺序选源：

1. 命令行上的 `--source <源 ID>`。
2. [配置文件](../config-tutorial/)里的 `source`。
3. 已加载扩展对完整 URL 的匹配。没有匹配项，或有多个匹配项时，CLI 会报错。

搜索没有作品 URL，短 ID 也不带站点信息，因此要显式指定源或使用配置中的默认源。配置里设了 `source` 时，即使传入另一个站点的完整链接，CLI 也会先按配置选源。可用 `--source` 临时覆盖。

## 精确选择章节

先运行 `comic-dl list "$series_url"`，核对输出顺序和每章第一列的稳定 ID。以下用 `101` 举例，使用时换成实际 ID：

```sh
comic-dl download "$series_url" -c 101 -c 2-4 -o ./downloads
```

- **按 ID**：只选与该 ID 对应的章节。若一个选择值恰好是已有 ID，即使长得像 `2-4`，也优先当作 ID。
- **按位置**：`2-4` 表示当前列表中的第 2 至第 4 项，含两端，从 `1` 开始计数，与章节标题中的数字无关。
- **混用**：重复传入 `-c`。CLI 会在下载前校验所有选择，去掉重复章节，再按列章顺序处理。找不到 ID、范围倒序或超界时，返回 `2`，不开始下载。

如果要在脚本里反复下载指定章节，优先保存稳定 ID；位置会随源返回的章节列表变化。

## 控制并发与失败重试

```sh
comic-dl download "$series_url" -o ./downloads --jobs 1 --retries 2
```

`--jobs` 是同时处理的章节数，默认 `2`；`--retries` 是暂态错误的额外重试次数，默认 `2`，设为 `0` 可关闭重试。

部分章节失败或受限时，其余章节会继续处理。按 `Ctrl+C` 可以中断，已完成的归档会保留。修正问题后，使用相同来源和输出目录重跑；通过完整性检查的 CBZ 会跳过。

## 在脚本中使用

`list` 和 `search` 的结果用制表符分隔，分页提示和错误写入标准错误。脚本应按退出码判断成败，而不是解析供人阅读的进度或汇总。部分章节受限时命令仍可能成功，详见 [CLI 输出与退出码](../../reference/cli/#脚本输出与退出码)。
