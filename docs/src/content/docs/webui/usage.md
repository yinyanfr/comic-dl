comic-dl-web 是 comic-dl 的单用户自托管 Web 界面。下载和追更由服务器完成，漫画直接写入管理员配置的目录；浏览器不传输漫画文件，也不是在线阅读器。关闭页面不会停止后台任务。

本页面向已能打开 WebUI 的用户。安装服务、配置环境变量和备份请看[部署指南](../deployment/)。

## 登录与界面

管理员启用密码后，先登录再访问页面、接口、封面和实时事件。默认登录随浏览器会话保存；勾选「记住我」可保留 30 天，服务端最长也为 30 天。服务重启使所有登录失效。浏览器可能恢复会话 Cookie，共享设备务必在「设置 → 管理员登录」主动退出。

页头或设置页可切换中文、English、日本語，语言偏好在当前浏览器保存一年；登录页也可切换。只翻译项目界面，漫画名、章节名、作者、简介、标签和来源声明的筛选项／字段保持原文。语言切换刷新当前 URL，不中断服务端任务。

设置页支持日间、夜间和跟随系统，外观偏好保存在当前浏览器。首页是书架，可切换详细／紧凑视图；紧凑模式点击管理图标打开完整操作。

## 浏览与搜索

1. 打开「浏览来源」，选择 CopyManga、Zerobyw、动漫屋／漫画人、Komga 或 Kavita。
2. 留空浏览或输入关键词搜索。排序、筛选和分页由各来源提供；搜索模式不一定支持浏览模式的全部选项。
3. 也可聚合搜索，结果按来源分组。单个来源不可用不代表其他来源失败。
4. 点击作品查看封面、元数据、简介和章节，加入书架或选择下载。

封面及详情取决于来源可提供的数据；缺失时显示占位，不代表下载必然失败。来源站点规则、地区、网络与账号权限仍然适用。

### 来源凭据

网页管理默认关闭，由管理员决定是否开启。启用后可在来源设置保存普通字段和内置来源的凭据；凭据保存后不回显。

| 来源           | 使用要点                                                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CopyManga      | 可匿名浏览；站点、API 地址与 User-Agent 由来源设置控制。                                                                                                          |
| Zerobyw        | 可匿名浏览／搜索，列章和下载需要有效 Cookie。通过登录链接在新标签页登录后，可从浏览器网络面板复制作品请求的 `Cookie` 请求头；不要将 Cookie 发到公开问题或截图中。 |
| 动漫屋／漫画人 | 可访问公开内容；当前内置扩展没有可编辑字段。                                                                                                                      |
| Komga          | 配置服务器地址和 API Key。                                                                                                                                        |
| Kavita         | 配置服务器地址和 Auth Key。                                                                                                                                       |

网页凭据绑定保存时的来源地址，修改地址后需重新保存；清除网页凭据后恢复使用部署环境凭据。「恢复默认」只重置普通设置。托管扩展覆盖内置版本时，网页保存的凭据不注入托管版本，请管理员按扩展说明配置。

## 书架与自动追更

从作品详情加入书架，或在书架展开「通过链接添加作品」。同一来源的同一作品去重，不同来源的版本独立。

- 点击作品标题可手选章节；「下载全部未下载章节」交给核心核对已有归档，并非提前显示本地章节清单。
- 「检查更新」检查单本；「检查全部作品」包括未启用自动检查的作品。
- 「自动检查」决定是否定期获取目录；「自动下载」决定新发现章节是否自动入队，两者独立。
- 开启／暂停自动追更的快捷按钮同时切换两个开关。
- 作品检查间隔留空时跟随全局；修改全局间隔不覆盖作品自己的间隔。

### 第一次检查为什么没下载？

首次成功检查默认只建立目录基线，避免把整个收藏自动下载。需要旧章节时，明确点击「补下载历史」，或手动选章。

关闭自动下载时，发现的新章保留在「新发现与待处理章节」，可逐章入队；之后开启自动下载**不会追溯入队**此前发现的章节。手动检查也遵守自动下载设置。

关闭任何开关都不会取消已有任务，取消必须单独操作。失败或受限章节可在处理好网络／账号问题后重试；移除书架条目不会删除已有归档。修改作品输入必须仍指向同源同作品。

## 手动下载与任务

在「手动下载」输入作品链接或短 ID，必要时选择来源，点击「查看章节」。勾选章节或输入包含两端的序号范围，例如 `2-4`；也支持来源可识别的章节直链。提交前会核对目录，目录已变化时需重新选章。

右上角下载管理合并显示手动和追更任务，按来源／作品分组，展示章节序号、处理阶段、页数和结果。可以取消、重试及清除已结束记录：

- 完整归档通过身份和完整性校验后跳过，不按文件名猜测。
- 一章失败不会掩盖其他章节的结果；重试只处理可重试章节，使用当前配置。
- 快照仅保留活动任务和有限近期记录，完整逐章结果可分页查看。
- 清除记录不删除归档或书架历史；清除追更记录仅影响当前进程的显示。
- 手动队列和历史只保存在进程内，重启不恢复；已完成文件保留，可重新提交并跳过完整归档。
- 追更队列持久化，重启继续处理；实时页数不持久化，重试时重新计算。

只下载你有权访问和备份的内容。文件保存在服务器，不会自动下载到手机或电脑；使用外部阅读器、Komga 或 Kavita 读取管理员配置的漫画目录。

## 归档设置与迁移

管理员开启网页管理后，可在设置页选择已有下载子目录、检查间隔、默认来源及归档策略。子目录须预先存在且位于输出根下，不能是符号链接；改变目录不移动旧文件。

默认路径为 `{title}/{number}-{chapter}.cbz`，支持 CBZ／ZIP、序号补零和最多四个路径段（含文件名）的模板。变量为 `{title}`、`{number}`、`{chapter}`、`{workId}`、`{chapterId}`；模板不包含扩展名。章节序号来自完整目录，不因选章改变；直链上下文不足时按章节 ID 回退。

改变模板、格式或来源排序不自动重命名，旧完整归档仍按稳定身份识别。需要改名时：

1. 请管理员备份归档，暂停其他 CLI、同步工具或阅读器的写入。
2. 等待或取消已有手动任务。
3. 在「设置 → 预览与迁移已有归档」选择单本或全书架并检查预览。
4. 确认后应用；冲突目标不会被覆盖，迁移不是整批事务，失败后应检查实际结果再重新预览。

预览十分钟有效，设置变更或服务重启后需重做。应用期间暂停 watcher，并阻止新手动任务。迁移只调整归档路径，不是数据库备份或内容转换。

## 扩展管理

市场列出内置推荐来源和实际加载状态。管理员启用管理后，可按 npm 包名及版本范围／标签安装托管扩展；扩展是在服务器运行的代码，只安装受信任的包。

托管版本优先于同来源的内置版本，卸载后恢复内置版本。内置依赖随 Web 镜像升级；托管版本需单独管理。

「检查更新」只查询，不安装。确认后才应用；应用时重新解析保存的范围，检查结果不是版本锁定。固定版本不会自动更新，`^0.2.0` 不包含 `0.3.0`，跨范围升级须显式指定新范围或标签。定义能加载不代表站点、账号和下载一定可用。

## 安装为应用（PWA）

通过 HTTPS 打开服务后：

- Chrome／Edge：使用地址栏或菜单中的安装入口。
- iPhone／iPad：浏览器分享菜单 → 添加到主屏幕。
- macOS Safari：添加到程序坞。

具体入口取决于系统和浏览器。普通 HTTP 局域网 IP 通常不满足安装条件，localhost／127.0.0.1 开发环境除外。

安装后使用项目图标并以独立窗口打开书架；仍需登录和连接服务器。没有 Service Worker、离线缓存或离线阅读功能。

## 常见问题

| 问题                 | 检查方向                                                                 |
| -------------------- | ------------------------------------------------------------------------ |
| 新章没有下载         | 是否已建立基线、启用自动下载？旧发现章节需手动入队；查看失败／受限结果。 |
| 目录暂不可用         | 请管理员恢复挂载标记或已选子目录，不要反复提交；追更保留队列等待恢复。   |
| 来源不可用／封面缺失 | 检查来源地址、账号和网络，确认实际加载的是内置还是托管版本。             |
| 实时进度停止         | 重连或刷新读取当前快照；让管理员检查代理的 SSE 缓冲和超时。              |
| 提示追更锁被占用     | 同一书架只允许一个 watcher，请管理员停止另一个实例。                     |
| 重启后需要重新登录   | 正常行为，登录状态只保存在服务进程中。                                   |
