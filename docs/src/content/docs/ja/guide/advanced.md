## 複数のソースから選択

`list`、`chapter`、`download` は以下の優先順でソースを選びます。

1. CLI の `--source <source-id>`。
2. [設定ファイル](../config-tutorial/)の `source`。
3. 読み込み済み拡張機能による完全 URL の照合。該当なし・複数該当はエラーです。

検索語や短い ID だけではソースを特定できないため、`--source` または設定内の既定値が必要です。別サイトの完全 URL を渡しても設定の `source` が優先されます。そのコマンドだけ変更するには `--source` を指定します。

## チャプターを選択

`comic-dl list "$series_url"` で順序と第 1 列の安定した ID を確認します。以下の `101` は実際の ID に置き換えてください。

```sh
comic-dl download "$series_url" -c 101 -c 2-4 -o ./downloads
```

- **ID 指定：** 一致する ID のチャプターを選択します。既存 ID と一致すれば、`2-4` のような値も ID として扱います。
- **位置指定：** `2-4` は現在の一覧の 2 番目から 4 番目までです。位置は `1` 始まりで、タイトル内の話数とは無関係です。
- **組み合わせ：** `-c` を繰り返して ID と範囲を混在できます。全指定を検証し、重複を除き、読み順に処理します。不明な ID、逆順・範囲外の指定はダウンロード前に終了コード `2` になります。

同じチャプターを繰り返し扱うスクリプトには安定した ID を使ってください。ソースの一覧更新により位置は変わることがあります。

## 並列数と再試行

```sh
comic-dl download "$series_url" -o ./downloads --jobs 1 --retries 2
```

`--jobs` は同時に処理するチャプター数（既定 `2`）、`--retries` は一時的エラー後の追加試行回数（既定 `2`）です。`0` で再試行を無効にできます。

ダウンロード時の作品・チャプター解決と各チャプター処理には、それぞれ独立した再試行枠があります。単独の `list` と `search` は一時的エラーに 2 回追加試行します。

一部が失敗・制限されても残りを処理します。`Ctrl+C` で中断しても完成したアーカイブは残ります。問題を解消したら同じソースと保存先で再実行してください。整合性検査を通った CBZ はスキップされます。

## スクリプトで使う

`list` と `search` はタブ区切りの結果を stdout に、ページ案内やエラーを stderr に出力します。人間向けの進捗や要約ではなく終了コードを確認してください。一部が制限されてもダウンロードが成功扱いになる場合があります。[CLI 出力と終了コード](../../reference/cli/#スクリプト向け出力と終了コード)を参照してください。
