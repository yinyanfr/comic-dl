4 は任意の `archive: { template, padding, format }` にも対応します。既定テンプレートは `{title}/{number}-{chapter}`、padding は `0`〜`12` の整数（既定 `0`）、形式は `cbz`（既定）または `zip` です。archive の不明項目は拒否します。プレースホルダーとパス制約は[バックエンド API](../../guide/service-api/)を参照してください。設定バージョンは `1` のままです。

`--config <file>` は UTF-8 JSON を指定します。最上位はオブジェクト、`version` は数値 `1` が必須です。不明フィールドは拒否し、それ以外は任意です。

| 項目         | 型と制約                       | 用途                              |
| ------------ | ------------------------------ | --------------------------------- |
| `version`    | 数値 `1`                       | 形式バージョン                    |
| `extensions` | 空でない文字列の配列。空配列可 | npm 名またはローカル ESM パス     |
| `source`     | `[a-z0-9]+(?:-[a-z0-9]+)*`     | 既定ソース ID。使用前に登録が必要 |
| `output`     | 空でない文字列                 | 既定の保存先                      |
| `jobs`       | `1` 以上の安全な整数           | `download` の最大並列数           |
| `retries`    | `0` 以上の安全な整数           | `chapter/download` の追加試行回数 |

1. 明示 CLI、設定、組み込み既定値の順です。出力指定なしの `download` は現在地。CLI 拡張一覧は設定一覧を丸ごと置き換えますが、`add` 済み拡張も読み込みます。
2. `output` の `~` と `~/` はホームです。他の相対出力と `./`、`../` 始まりの拡張パスは設定ファイル基準です。絶対パスは維持し、パッケージ名はモジュール解決に従います。
3. 各オプションは関連コマンドのみ有効です（例：`list` は `output` を使わない）。読み込み時にすべての型・制約を検証します。
4. 認証情報は形式の対象外です。読み込み不能、不正 JSON・項目・バージョンは終了コード `2` です。

任意の `sourceSettings` はソース ID をキーとするオブジェクトです。各値の設定キーは `[a-z][a-z0-9-]*`、値は文字列・真偽値・安全な整数です。対応キー・型・範囲は拡張が定義し、使用時に検証します。`--set <id>.<key>=<value>` で個別上書きでき、真偽値は `true/false` を使います。
