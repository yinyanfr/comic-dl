---
title: 配置文件 v1
description: CLI JSON 配置的字段、校验、合并顺序和路径规则。
---

`--config <file>` 显式指定一个 UTF-8 JSON 文件。顶层必须是对象，要求 `version` 为数字 `1`。不接受未知字段；除 `version` 外，所有字段均可省略。

| 字段         | 类型与约束                               | 作用                                           |
| ------------ | ---------------------------------------- | ---------------------------------------------- |
| `version`    | 数字 `1`                                 | 配置格式版本                                   |
| `extensions` | 非空字符串数组，可为空数组               | 要加载的扩展；可用 npm 包名或本地 ESM 文件路径 |
| `source`     | 匹配 `[a-z0-9]+(?:-[a-z0-9]+)*` 的字符串 | 默认源 ID；必须已注册才能选用                  |
| `output`     | 非空字符串                               | 默认下载目录                                   |
| `jobs`       | 大于或等于 `1` 的安全整数                | `download` 的最大并行章节数                    |
| `retries`    | 大于或等于 `0` 的安全整数                | `chapter` 和 `download` 的额外重试次数         |

1. 命令行的显式值优先，其次是配置值，最后是内置默认值。命令行扩展列表整组替换配置列表。
2. `output` 和以 `./` 或 `../` 开头的本地扩展路径相对于配置文件目录解析。绝对路径仍按绝对路径解释，包名按模块解析规则处理。
3. 配置中的选项只有在相关命令中才生效；例如 `list` 不使用 `output`。字段类型和取值约束在读入时统一校验。
4. 凭据不属于配置格式。文件读取失败、无效 JSON、字段错误和不支持的配置版本返回退出码 `2`。
